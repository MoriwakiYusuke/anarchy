# Feature Specification: Frontend UI Redesign

**Feature Branch**: `005-frontend-ui-redesign`  
**Created**: 2026-02-08  
**Status**: Draft  
**Input**: User description: "フロントエンドUI改善: 多言語対応(日英中)、cMatrixスタイル背景、Blood Glitchテーマ"

## Overview

Anarchyフロントエンドの視覚的改善と国際化対応。既存の「黒・白・赤」カラースキームを活かしつつ、cMatrixスタイルの背景アニメーションと3言語対応を実装する。

### Design Philosophy

- **Anarchy世界観の維持**: 既存の黒・白・赤の統一感を崩さない
- **背景は控えめに**: コンテンツエリアを邪魔せず、端から覗く程度の存在感
- **Blood Glitchテーマ**: 静かな中に不気味さと力強さが同居する「支配なき秩序」の表現

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 多言語での利用 (Priority: P1)

日本語・中国語・英語を母語とするユーザーが、自分の言語でAnarchyを使用できる。ブラウザの言語設定に基づいて自動的に適切な言語が選択され、手動での切り替えも可能。

**Why this priority**: 国際的なユーザー基盤の拡大に直結し、非英語圏ユーザーのアクセシビリティを大幅に向上させる。

**Independent Test**: 言語切り替え機能のみを実装し、UIテキストが正しく切り替わることを確認できる。

**Acceptance Scenarios**:

1. **Given** ブラウザ言語が日本語のユーザー, **When** サイトにアクセス, **Then** UIが日本語で表示される
2. **Given** 任意の言語で表示中, **When** 言語切替ボタンをクリック, **Then** 利用可能な言語リスト（EN/JA/ZH）が表示される
3. **Given** 言語リストを表示中, **When** 別の言語を選択, **Then** 即座にUI全体がその言語に切り替わる
4. **Given** 言語を手動で選択済み, **When** 次回サイトにアクセス, **Then** 前回選択した言語が維持される

---

### User Story 2 - cMatrix背景体験 (Priority: P2)

ユーザーがAnarchyにアクセスすると、画面背景にcMatrixスタイルの文字落下アニメーションが表示される。通常はダークグレーの落ち着いた表示だが、時折赤い文字が「グリッチ」として現れ、Anarchyの世界観を演出する。

**Why this priority**: ブランドアイデンティティの強化と視覚的差別化。機能的には必須ではないが、ユーザー体験とプロジェクトの印象を大きく向上させる。

**Independent Test**: 背景コンポーネントのみを実装し、アニメーションが正しく動作することを確認できる。

**Acceptance Scenarios**:

1. **Given** サイトにアクセス, **When** ページが読み込まれる, **Then** 背景にcMatrix風の文字落下アニメーションが開始される
2. **Given** アニメーション実行中, **When** 約2%の確率で, **Then** 文字が赤色（#CC0000）で表示される「Blood Glitch」効果が発生
3. **Given** コンテンツエリア（ウォレット接続、投稿フォーム等）表示中, **When** 背景アニメーション実行中, **Then** コンテンツの可読性が損なわれない
4. **Given** モバイルデバイスでアクセス, **When** ページ読み込み, **Then** 背景アニメーションがデバイス性能に応じて調整される

---

### User Story 3 - 視覚アクセシビリティ対応 (Priority: P3)

動きに敏感なユーザーや、パフォーマンスを優先したいユーザーが、背景アニメーションを無効化できる。

**Why this priority**: アクセシビリティとユーザー選択の尊重。一部ユーザーにとって重要だが、大多数には影響しない。

**Independent Test**: アニメーション停止機能を単独でテストできる。

**Acceptance Scenarios**:

1. **Given** `prefers-reduced-motion: reduce`設定のブラウザ, **When** サイトにアクセス, **Then** 背景アニメーションが自動的に無効化される
2. **Given** 設定メニューまたはUI上のトグル, **When** アニメーションをOFFに切り替え, **Then** 背景が静的な状態になる

---

### Edge Cases

- 言語ファイルの読み込みに失敗した場合、英語（デフォルト）にフォールバックする
- ブラウザのCanvas APIが利用できない場合、背景は単色（#0a0a0a）で表示される
- 非常に低スペックなデバイスでは、アニメーションのフレームレートを自動的に下げる
- localStorageが利用できない場合、言語設定はセッション中のみ保持される

## Requirements *(mandatory)*

### Functional Requirements

#### 多言語対応

- **FR-001**: システムは英語（EN）、日本語（JA）、中国語簡体字（ZH）の3言語に対応しなければならない
- **FR-002**: デフォルト言語は英語でなければならない
- **FR-003**: ブラウザの`navigator.language`または`navigator.languages`に基づいて初期言語を自動検出しなければならない
- **FR-004**: ユーザーは言語切替UIから手動で言語を変更できなければならない
- **FR-005**: 選択された言語設定はブラウザに永続化されなければならない
- **FR-006**: 以下のUI要素は全て翻訳対象としなければならない:
  - ナビゲーション要素
  - ボタンラベル
  - フォームプレースホルダー
  - エラーメッセージ
  - 成功メッセージ

#### cMatrix背景

- **FR-007**: 背景にcMatrixスタイルの文字落下アニメーションを表示しなければならない
- **FR-008**: アニメーションはCanvas APIを使用して実装しなければならない
- **FR-009**: 文字落下の基本色はダークグレー（#333333）、先頭文字はライトグレー（#999999）でなければならない
- **FR-010**: 約2%の確率で文字色が赤（#CC0000）になる「Blood Glitch」効果を実装しなければならない
- **FR-011**: アニメーション更新間隔は50ms〜80msの範囲でなければならない
- **FR-012**: 背景アニメーションはコンテンツレイヤーの背後に配置され、コンテンツの視認性を妨げてはならない

#### アクセシビリティ

- **FR-013**: `prefers-reduced-motion: reduce`メディアクエリを尊重し、該当する場合はアニメーションを無効化しなければならない
- **FR-014**: コンテンツエリアと背景アニメーションのコントラスト比は、WCAG 2.1 AA基準を満たさなければならない

### Key Entities

- **LocaleConfig**: 言語設定（locale code, display name, fallback locale）
- **TranslationMap**: キーと翻訳文字列のマッピング（namespace別に整理）
- **MatrixConfig**: 背景アニメーション設定（速度、色、密度、Blood Glitch確率）

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 日本語・中国語・英語の各言語で全てのUIテキストが正しく表示される
- **SC-002**: 言語切り替え後、500ms以内にUI全体が新しい言語で再描画される
- **SC-003**: 背景アニメーションが60fps（または端末能力の最大値）で滑らかに動作する
- **SC-004**: Blood Glitch効果が視認可能な頻度（約2%）で発生する
- **SC-005**: コンテンツエリアのテキスト可読性が背景アニメーションにより損なわれない
- **SC-006**: `prefers-reduced-motion`設定時、背景アニメーションが完全に停止する
- **SC-007**: 初回ページ読み込み時、背景アニメーションの初期化が1秒以内に完了する

## Assumptions

- 翻訳テキストは開発チームが提供する（外部翻訳サービスは使用しない）
- 中国語は簡体字のみ対応（繁体字は将来の拡張として検討）
- 対象ブラウザはCanvas APIをサポートするモダンブラウザ（Chrome, Firefox, Safari, Edge の最新2バージョン）
- モバイルデバイスでのアニメーションパフォーマンスは、デスクトップより低くなる可能性がある

## Dependencies

- 既存のNext.jsフロントエンド構造
- 現行の黒・白・赤カラースキーム
- ウォレット接続、投稿フォーム等の既存コンポーネント

## Out of Scope

- 3言語以外の言語サポート
- サーバーサイドでの言語検出
- 背景アニメーションのカスタマイズUI（色やスピードの調整）
- A/Bテストや背景テーマの切り替え機能
